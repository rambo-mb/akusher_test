# Akusherlik Test — Telegram Bot Sozlamalari (BotFather)

Bu hujjat botni @BotFather orqali to'g'ri sozlash bo'yicha yo'riqnoma.

## 1. Asosiy ma'lumotlar
BotFather-ga kirib, botingizni tanlang (`/mybots` -> Botingiz).

- **Name** (`/setname`): `Akusherlik Test`
- **About** (`/setabouttext`): `Akusherlik va ginekologiya bo'yicha imtihonlarga tayyorgarlik ko'rish uchun maxsus test ilovasi. Bilimingizni tekshiring va natijalarni yaxshilang!`
- **Description** (`/setdescription`): 
```
🎓 Akusherlik va Ginekologiya testlariga tayyorgarlik!

Bu yerda siz:
- Asosiy mavzular bo'yicha bilimlaringizni sinab ko'rishingiz
- Qiyin savollar bilan ishlashingiz
- Kundalik reytinglarda ishtirok etishingiz mumkin.

Testni boshlash uchun pastdagi tugmani bosing 👇
```

## 2. Rasm (Userpic) o'rnatish
- `/setuserpic` buyrug'ini bering va ushbu papkadagi `logo.png` faylini rasm (photo) sifatida yuboring.

## 3. Buyruqlar (Commands) o'rnatish
- `/setcommands` ni tanlang va quyidagi ro'yxatni yuboring:

```
start - Botni ishga tushirish va testga kirish
help - Yordam va ma'lumot
myid - Sizning shaxsiy Telegram ID raqamingiz
```

## 4. Mini App (Web App) sozlamalari
Agar hali Mini App yaratmagan bo'lsangiz:
- `/newapp` -> Botingizni tanlaysiz -> App nomi: `Akusherlik Test` -> Qisqa nom (masalan `akusher_test`) -> Web App URL (sizning web app manzilingiz).

Agar allaqachon yaratilgan bo'lsa:
- `/myapps` -> Ilovani tanlaysiz -> **Edit name**: `Akusherlik Test`
- **Edit Description**: Ilova haqida qisqacha ma'lumot.
- **Web App Photo**: `logo.png` ni yuboring (ko'k rangdagi logotip qidiruv va ro'yxatlarda chiqishi uchun).
